# Результаты проверки — 13 октября 2026

Проверено на Windows, Node.js 24.14.0, настоящей PostgreSQL 16.11 в отдельном тестовом кластере (127.0.0.1:55439). Использовалось приложение на порту 3309; параметры передавались переменными окружения. В `.env.example` оставлены стандартные порты 3000/5432 для запуска по README.

| Проверка | Результат |
| --- | --- |
| `npm install` | Успешно; версии зафиксированы в package-lock.json |
| `npm run build` | Успешно |
| `npm run typecheck` | Успешно |
| `migration:generate` | Начальная миграция сгенерирована из entity |
| `migration:run` | Применена на пустой базе |
| `migration:revert` и повторный `migration:run` | Успешно |
| TypeORM `schema:log` | Отличий entity от схемы нет |
| HTTP e2e | 1 комплексный тест пройден, 0 ошибок |
| Swagger | `/api` возвращает HTML с HTTP 200; `/api-json` содержит маршруты и схемы |
| FK | Подтверждён запросом к pg_constraint и выводом psql |
| N+1 | Для 3 продавцов: до — 4 SELECT, после — 1 SELECT |

HTTP-тест выполняет реальные запросы ко всем десяти операциям API: создание, чтение списка, чтение по id, обновление и удаление каждой сущности. Дополнительно проверяет уникальность email, запрет лишних полей и null, ограничения цены, несуществующего продавца, ILIKE, все варианты сортировки, границы пагинации, страницу за пределами списка, все товары продавца в странице, смену продавца и ON DELETE CASCADE.

Docker в среде подготовки отсутствует, поэтому именно запуск Docker Compose не проверялся. Проверки БД выполнены на локальном сервере PostgreSQL. Клики по методам в Swagger UI вручную не выполнялись: маршруты проверены автоматическими HTTP-запросами, доступность UI и OpenAPI проверена отдельно. Пошаговая ручная проверка через Swagger приведена в README.
